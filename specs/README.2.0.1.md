## Directory Files: content and reading order

The MarkdownToLaTeX project contains a Files directory.
Files contains (non exclusively) the following files, sorted by reading priority

1. CHANGELOG: Keep track of changes. If a file is mentioned in the changelog, read it. If not, then do not.
2. README.*.md: the current file
3. mission.*.md: describes the goals of the Project
4. kaizen.*.md: the Project paradigm and rules
5. scopeStatement.*.md: the scope statement
6. specifications.formal.*md
7. specifications.code.*.md: design and specifications for implementation.
8. nextStep.*.md: the current step
